**BloodBankDBMS**

A comprehensive Blood Bank Management System implemented using relational databases (MySQL), designed to streamline donor, blood inventory, and request management for blood banks.

---

Features:

- **Donor Management:** Add, view, update, and delete donor records.
- **Blood Inventory Management:** Track blood types, quantities, and expiration dates.
- **Blood Requests:** Handle patient requests — log, approve, and fulfill.
- **Search & Reporting:** Filter donors by blood type/location; generate real-time inventory and usage reports.
- **Validation:** Ensure data integrity with proper constraints and checks.
